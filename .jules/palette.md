## 2024-05-19 - Null content descriptions for decorative versus action icons
**Learning:** In Compose, some `Icon`s use `contentDescription = null` legitimately (e.g. decorative or alongside explicit text in a `Button`). However, icons acting as the sole visual indicator (e.g., `IconButton` wraps or leading status icons in settings) need explicit string resources to prevent screen readers from announcing them as unlabelled buttons or ignoring important status contexts.
**Action:** When adding or refactoring icons, evaluate if the surrounding context (like a parent `Button` text) is sufficient. If the icon acts as the primary action target (`IconButton`) or key visual status, provide a localized `contentDescription`.
