## 2024-08-31 - [AudioTrack FloatArray Conversion Optimization]
**Learning:** In the local TTS synthesizer `AudioTrackPlayer`, native PCM samples were generated as a `FloatArray` but manually clamped and converted to a `ShortArray` via an iterative loop before being passed to `AudioTrack`. Because the app's `minSdkVersion` is 26, we can directly write the `FloatArray` to the `AudioTrack` by configuring it with `AudioFormat.ENCODING_PCM_FLOAT`, bypassing the CPU-heavy loop and intermediate array allocation.
**Action:** When streaming native `FloatArray` audio data in Android using `AudioTrack` (API 21+), always set `ENCODING_PCM_FLOAT` and write the `FloatArray` directly instead of manually clamping and coercing into `short[]`. Also, remember that `bufferSize` calculation needs to multiply by 4 (bytes per float) rather than 2 (bytes per short).
